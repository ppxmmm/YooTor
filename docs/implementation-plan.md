# YooTor — Thai family legacy MVP

Build Next.js App Router + TypeScript, Prisma/PostgreSQL, Thai-first UI. The user authorized autonomous implementation and explicitly opted out of repeated clarification. Visual direction: warm white, deep navy sidebar, teal functional accents, delicate borders, quiet readable Thai typography; complete dashboard with readiness, assets, next actions, activity. Marketing homepage and all product routes share this system.

1. Backend: normalized schema, migrations, seed, secure cookie sessions, scrypt passwords, Zod validation, resource authorization, private encrypted files, audit, explicit owner-reviewed family grants, deterministic Thai assistant and optional provider.
2. Frontend: landing, registration/onboarding, app shell/dashboard, assets, contacts, documents, instructions, family, checklist, assistant, tax, settings. Functional forms and persisted interactions.
3. Integrate and verify: actual local persistence (PostgreSQL preferred; local encrypted demo fallback only if unavailable), auth/isolation/permissions tests, browser journeys, responsive views, lint/typecheck/build. Document limits accurately.

No automatic legal action, no bank credentials, no automatic unlocking after reported death. Guidance references are versioned and conditional. Production compliance, email delivery, identity review, malware scanning and deployment key management require external setup/review.
